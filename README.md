# AI Website Generator

Describe a webpage in plain text and get a fully working HTML + Tailwind CSS page generated in seconds. Edit any element visually by clicking it in the live preview, then export or download the result.

## Stack

Next.js · TypeScript · Clerk · OpenRouter · Neon + Drizzle · ImageKit · shadcn/ui
